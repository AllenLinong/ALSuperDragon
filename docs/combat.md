# 技能与应对

[返回 Wiki 首页](README.md) · [默认配置](../src/main/resources/config.yml)

以下是默认技能。到达门槛仅表示加入技能池或排队触发，并不表示所有技能同时施放。表中的配置名均位于 `skills` 下。

| 技能 | 默认条件 | 应对 |
| --- | --- | --- |
| 强化火球 `fireball` | 66.67% 血量及以下加入技能池 | 看到预警就离开锁定位置。 |
| 冲击波 `shockwave` | 无单独血量门槛 | 离开预警范围；同一次扩散最多命中每人一次。 |
| 俯冲 `dive` | 前期单次，66.67% 血量及以下改为三连 | 避开落点，连击阶段躲过第一击也不要停下。 |
| 蓄力激光 `laser` | 33.33% 血量及以下加入技能池 | 离开光束路径，或借方块遮挡。 |
| 群龙俯冲 `dragon-rush` | 75%、50%、25% 各一次 | 每次五只小龙，盘旋后错开冲向玩家；注意队友及身边的落点。 |
| 末影人怒吼 `ender-roar` | 80%、60%、40%、20% 各一次 | 留意被激怒的末影人。 |
| 龙蛋位水晶 `podium-crystal` | 55% 血量时排队，每条龙一次 | 在默认 10 秒倒计时内打碎水晶，或离开 50 格预警圈。来不及走时，波纹扫到前面向水晶举盾。 |
| 终局冲击 `finale` | 10% 血量时，每条龙最多一次 | 默认预警 4 秒，跑出 20 格范围；不死图腾可救命。 |

挡住龙蛋位水晶涟漪后保留命中时的 10% 生命，并免疫该水晶的残留龙息；未挡住时默认基础爆炸伤害为 99999 点。该技能不破坏地形。

## 扩展技能

| 技能 | 血量门槛 / 冷却 | 应对 |
| --- | --- | --- |
| 浮空阵 `levitation-field` | 85% / 28 秒 | 离开脚下的预警圈。 |
| 衔空 `sky-bite` | 75% / 45 秒 | 躲开冲刺；被抓时仍可攻击龙，松口后按原版规则计算摔落。 |
| 龙息喷涌 `breath-eruption` | 65% / 35 秒 | 避开预警范围与原地留下的龙息云。 |
| 水晶裂爆 `crystal-burst` | 40% / 40 秒 | 避开至多三个爆点；重叠区域同次不会重复判伤。 |
| 追踪激光 `tracking-laser` | 30% / 30 秒 | 光束跟踪约半秒前的位置；持续横向走位或用方块遮挡。 |

塔顶水晶全数摧毁后注意幻翼增援，默认每条龙触发一次。血条会显示主龙当前和最大生命值，可用于判断接下来的技能门槛。
